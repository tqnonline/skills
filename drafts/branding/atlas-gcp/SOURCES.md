Inspect relevant official diagrams for grouping, whitespace and boundaries, not as mandatory service inventories. A small Cloud Run/ADK example can guide a simple runtime; a multi-tenant internal-agent pattern does not prove commercial SaaS isolation. Google product labels, API names and ZIP members may differ. Preserve explicit aliases; never invent a product-specific icon from a similar category.

Do not bundle whole icon archives into this text-distributed skill. Fetch selected official assets at run time or accept a supplied official package. Record URL, package filename/version if published, retrieval date, archive SHA-256, original member path and per-file SHA-256. No private attachment URL may remain a runtime dependency. The research attachment supplied for this implementation is incomplete and is not an asset license.

List and validate the complete archive before extracting selected SVGs. Reject traversal, absolute paths, symbolic links, duplicate members, unexpected file types and excessive expanded size/ratios. Run `scripts/assets.py --help` for the selected-member acquisition interface. Preserve original bytes. Run the assembler's SVG validation before embedding; current official packages can contain inert CSS, but imports, escaped URLs, scripts and unknown CSS are not permitted.

Keep product names adjacent to artwork; do not recolor, crop, rotate, reflect, distort or present icons as the SaaS product's own mark. Cite the official asset page and retain a rights note. The repository's Apache license does not grant rights in Google brand features. If redistribution terms or a product mapping are unclear, disclose the uncertainty and seek the appropriate approval; an official download or valid hash alone does not establish broad redistribution rights.
